# 製缶溶接ツール

製缶の現場で使う計算をまとめたWebアプリです。

**開く：** https://tomy-orgon.github.io/seikan-tool/

- 溶接ピッチ（通常・千鳥）
- 円周割付（角度 → 弦・円弧、等分で一括入力）
- 三角計算
- 材料切断（定尺からの取り数・切断指示書）
- 重量計算（材料切断の品目をそのまま送って計算できる）

一度開けば、電波がなくても使えます。スマホではホーム画面に追加するとアプリのように使えます。
不具合や要望は、ツール上部の「要望・不具合を送る」からどうぞ。

## 更新するとき
`sw.js` の `VER` を変えると、使っている人の端末でも新しい版に切り替わります。
